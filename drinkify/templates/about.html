how it works

no AI. just a lookup table, some arithmetic and good taste.

  1. we look the artist up on MusicBrainz and read their genre tags, the votes on each tag, where they're from, when they started, and whether they're a person, a band or an orchestra.
  2. each tag is matched against {{ n_genres }} genres (plus {{ n_aliases }} other spellings). unknown sub-genres fall back to the genre they end with: "swedish melodic death metal" counts as death metal.
  3. every genre has a flavor profile (strength, sweet, sour, bitter, smoky, fizzy, fruity, herbal, creamy, rich), favorite spirits and a vibe. the artist's profile is the vote-weighted mix of their genres.
  4. all {{ n_drinks }} drinks get a score: {{ (weights[0]*100)|round|int }}% flavor match, {{ (weights[1]*100)|round|int }}% spirit match, {{ (weights[2]*100)|round|int }}% vibe match, {{ (weights[3]*100)|round|int }}% local color (country, era, band size).
  5. highest score wins. near-ties are broken by a hash of the artist's id, so the same artist always gets the same drink.

a homage to the original drinkify.
